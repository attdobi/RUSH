Label-noise crank simulator

A judge panel labels 2D points by reading the current policy boundary; panel-vs-human misalignment picks anchors; a clipped gradient step drafts a candidate boundary; a gate accepts it only if macro-F1 against the human test labels does not drop. Human labels are noisy. Every run simulates two coupled universes over the same world with common random numbers — the noisy one (corrupted human labels) and its clean twin (labels = ground truth) — so any gap between them is attributable to label noise alone. Bayesian per-label confidence can deweight (or upweight) suspect anchors, and a budgeted SME queue re-adjudicates the most suspicious labels.

Mirrors sim/label-noise/labelsim v0.1 semantics (GenAI binary arm). Fully seeded: any control change deterministically re-runs the whole trajectory, then animates it.
